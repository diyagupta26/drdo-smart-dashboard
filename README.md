# DRDO Smart Dashboard

## Overview
DRDO Smart Dashboard is a full-stack web application developed using React, Node.js, Express.js, and PostgreSQL for efficient dashboard management and real-time data visualization.

## Tech Stack
- React
- TypeScript
- Node.js
- Express.js
- PostgreSQL
- Drizzle ORM
- Tailwind CSS

## Features
- RESTful APIs
- Authentication and authorization
- Real-time dashboard updates
- Database integration
- Responsive UI

## Installation

```bash
npm install
npm run dev
